# HoriCraft テスト版リポジトリ（テスター専用）

発売前のテスト版を、テスターの方に VCC / ALCOM で配るための場所です。
**正式版はここには置きません。** 正式版は HoriCraft の通常のリポジトリから配布します。

- 登録URL: `https://horicraft.github.io/vpm-beta/index.json`
- ここにある版は `-beta.N` の付いたテスト版だけです。不具合を含む可能性があります。
- テストが終わったら、VCC / ALCOM の Settings → Packages からこのリポジトリを削除してください。
