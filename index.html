MeshEraser テスト版

テスターの方向けの導入ページです（1.1.0-beta）

テストのお願い

テストへのご協力、ありがとうございます！

いま MeshEraser の次のアップデート（v1.1）を準備していて、発売前に実際に使ってもらい、動きを確かめたいと思っています。

やってもらいたいことは、このページの手順でテスト版を入れて、確認シートの項目を上から試し、ボタンで結果を選ぶだけです。期限はありません。全部やらなくても大丈夫で、できた所まで、都合のよいときに送ってもらえればとても助かります（目安は30分〜1時間くらいです）。

特に見てほしいのは、次の3つです。

  • 自分のアバターで使って、動きがおかしい所（形が伸びる、消えない、エラーが出る など）
  • 使っていて分かりにくかった所、迷った所
  • ALCOM での入れ方で迷った所（正式版も同じ入れ方にする予定です）

「これで合ってるのかな？」と思ったことも、そのまま書いてもらえるとうれしいです。分からないことがあれば、いつでも Discord の DM で聞いてください。

発売前のテスト版です。このページのURLやテスト版を、ほかの人に教えたり公開したりしないでください。念のため、テスト用にコピーした Unity プロジェクトで試してもらえると安心です。正式版はここでは配りません。

1. ALCOM / VCC にリポジトリを追加

ALCOM / VCC に追加

押すと ALCOM（または VCC）が開き、追加の確認が出ます。［追加］（Add）を押してください。
ブラウザに「ALCOM を開きますか？」と出たら［開く］を選びます。

ボタンで開かないとき（手で追加する）

ALCOM の「設定」→「パッケージ」→［リポジトリを追加］に、次のURLを貼り付けてください（VCC は Settings → Packages → Add Repository）。

https://horicraft.github.io/vpm-beta/index.json

2. 「プレリリースパッケージを表示」をON

ALCOM の「設定」→「パッケージ」で「プレリリースパッケージを表示」をONにします（VCC は Settings → Packages → Show Pre-Release Packages）。
テスト版は番号に -beta が付いているため、OFFのままだと一覧に出てきません。

3. プロジェクトに MeshEraser を追加

  1. 以前の MeshEraser が入っているプロジェクトなら、Unity で Assets/HoriCraft/MeshEraser フォルダだけを削除します（1つ上の HoriCraft は消さないでください。消し範囲はアバター側に残ります）。
  2. ALCOM でプロジェクトの管理画面を開き、MeshEraser（1.1.0-beta の付いた版）を追加します。
  3. 「NDMF が見つからない」と出たら、Modular Avatar のリポジトリも追加してください。
    Modular Avatar（NDMF）のリポジトリを追加
  4. Unity を開き、上部のメニュー HoriCraft → MeshEraser で開けば完了です。

4. 確認シートで試して、結果を送る

確認シートを開く
  1. 最初に「あなたの環境」を書きます（Unity のバージョン、使ったアバターなど）。
  2. 上から試して、各項目の［OK］［おかしい］［できなかった］を押します。おかしいときは「何をした／何が起きた／どうなってほしかった」を短く書いてください。
  3. 最後に［結果をコピーして送る］を押し、Discord の DM に貼り付けて送ってください。スクリーンショットがあれば一緒にどうぞ（Win＋Shift＋S で撮れます）。

入力はブラウザに自動で保存されるので、途中でやめても同じブラウザで開けば続きからできます。

製品版にする（解除）

MeshEraser の画面の［製品版をお持ちの方：旧製品版ファイルで認証］を押し、以前 BOOTH で受け取った製品版の zip か unitypackage を選んでください。お持ちでない場合は「お試し版」のままで試せます。

新しいテスト版が出たら・終わったら

  • 新しいテスト版は、プロジェクトの管理画面で［更新］を押すだけで入れ替わります。
  • テストが終わったら、ALCOM の設定からこのリポジトリを削除してください。
